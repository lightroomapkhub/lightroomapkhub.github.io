# Lightroom APK Guide

An independent, professional guide website about the Lightroom mobile photo editor — features, presets, editing tutorials, and honest safety information.

Live site: https://lightroomapk.github.io/

## What this site is

- 20 original guides (600–900 words each) on Lightroom editing: presets, portraits, landscapes, color grading, masking, export settings, and more
- 4 free in-browser tools: Preset Simulator, Exposure Triangle Explainer, Aspect Ratio & Crop Calculator, Photo Export Size Calculator
- Honest safety information about Lightroom Mod APKs, and how to install the official app from Google Play / the App Store

## What this site is NOT

This is an informational guide site only. It does **not** host, link to, or provide any APK file — modified or otherwise. The only download links on the site point to the official Adobe Lightroom app on Google Play and the Apple App Store.

## Tech

Pure HTML/CSS/vanilla JavaScript, no build step, no tracking. All tools run entirely in the browser. Hosted on GitHub Pages.
